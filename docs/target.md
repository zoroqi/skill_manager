這是一個關於本地 Skill 管理工具的需求構思。

該工具的主要目標是管理本地的 Skill。目前的核心訴求是解決 AI Agent 在全局環境安裝多個 Skill 後產生的上下文污染問題。儘管 Skill 本身引入的內容很少，但由於每個人編寫 Skill 的方式不同，可能會導致 Agent 選擇錯誤的 Skill。

例如，在程式碼倉庫中不需要寫文章或負責論文研究的技能；在 Java 專案中不需要 Go 語言相關的技能，反之亦然。

因此，該專案的核心目標是實現本地不同專案及全局環境的 Skill 管理。目前的主要解決的問題：

1. 對本地 Skill 進行管理
2. 對 AI Agent 的全局 Skill 配置進行統一管理與變更。
3. 可以針對每個專案進行單獨的 Skill 配置。
4. 能夠快速地對一個專案進行 Skill 的創建與初始化。
